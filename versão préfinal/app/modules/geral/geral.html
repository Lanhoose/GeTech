Introdução ao Sistema

O ERP Industrial GeTech é uma plataforma de gestão e monitoramento fabril de alta performance desenvolvida de forma modular. O ecossistema simula perfeitamente uma infraestrutura empresarial real, segregado de forma segura em duas frentes de atuação: o Portal Público Institucional e o Dashboard Interno Operacional (protegido por regras rígidas de autenticação).

Este portal de documentação serve como central técnica activa para a manutenção, onboarding de engenheiros e controle de pendências de desenvolvimento.

Tecnologias Utilizadas

Tecnologia Uso no Projeto Onde Aparece
HTML5 Estruturação semântica de interfaces, módulos e modais de dados. Todo o escopo de arquivos .html do sistema.
CSS3 Estilização avançada baseada em CSS Variables nativas, Flexbox e Grid layouts. Diretórios assets/css/ do App e do Site Público.
JavaScript (ES6) Lógica comportamental local, controle de ponto em tempo real e simulações do banco. Diretórios assets/js/ de controle relacional.
Fetch API Injeção assíncrona modular de cabeçalhos e rodapés reutilizáveis. Componente genérico component.js.
Web Storage Persistência local leve de sessões autenticadas e registros pragmáticos de usuários. Módulos de login e espelhos de ponto (localStorage).

Criação de Novos Módulos ERP

Para expandir o barramento operacional e adicionar novos cartões de gestão ao Dashboard, siga estritamente a padronização arquitetural mapeada abaixo:

Estrutura de Arquivo Obrigatória:
Sempre inicialize o módulo criando o ficheiro em: app/modules/nome-modulo/nome-modulo.html

Após a criação da interface isolada, importe os estilos compartilhados do sistema incluindo a tag de referência no cabeçalho do arquivo:

<link rel="stylesheet" href="/app/assets/css/global.css">

Por fim, anexe o gatilho de execução injetando o novo bloco de código HTML diretamente na Grid de Módulos dentro de app.html:

<div class="card" onclick="abrirModulo('nome-modulo')"> ... </div>
