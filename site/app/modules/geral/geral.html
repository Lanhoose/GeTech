Introdução ao Sistema

Sistema de gestão industrial desenvolvido como projeto educacional, simulando um ERP real com múltiplos módulos. Dividido em site público (institucional), app interno (protegido por autenticação) e Site C (portal de acesso direto ao cliente).

Linguagem
HTML, CSS, JavaScript puro
Armazenamento
localStorage / sessionStorage
Servidor necessário
Live Server (VS Code) ou qualquer HTTP
Dependências externas
Nenhuma (zero bibliotecas)
⚠️ Use a extensão Live Server no VS Code e abra public/pages/index.html. O fetch() dos componentes requer protocolo HTTP — abrir direto no navegador não funciona.

Sistema de Componentes

Header e footer são carregados via fetch() em todas as páginas públicas. Evita duplicação de código.

// component.js function carregarComponente(id, arquivo) { fetch(arquivo) .then(res => res.text()) .then(data => { document.getElementById(id).innerHTML = data; }); } document.addEventListener("DOMContentLoaded", () => { carregarComponente("header", "../components/header.html"); carregarComponente("footer", "../components/footer.html"); });
⚠️ O fetch() é bloqueado quando o arquivo é aberto via file://. Use sempre um servidor HTTP.

Autenticação

EtapaArquivoO que acontece
1. Cadastrologin.jsSalva {email, senha} no localStorage como JSON
2. Loginlogin.jsCompara credenciais, seta logado: "true" e redireciona
3. Proteçãoapp.jsVerifica logado === "true" ao carregar; redireciona se falso
4. Logoutapp.jsRemove a chave logado e volta para index
💡 Desafio da aula: migrar de localStorage para sessionStorage. A diferença: sessionStorage é apagado ao fechar a aba.

Como Criar uma Nova Página Pública

1. Copie o template

cp public/pages/_template.html public/pages/minha-pagina.html

2. Estrutura mínima obrigatória

<div id="header"></div> <!-- carregado pelo component.js --> <main class="container"> <!-- conteúdo da página --> </main> <div id="footer"></div> <!-- carregado pelo component.js --> <script src="../assets/js/component.js"></script>

3. Adicione no header

Edite public/components/header.html e adicione o link na tag <nav>.

Como Criar um Novo Módulo ERP

1. Crie a pasta e arquivo

app/modules/nome-modulo/nome-modulo.html

2. Importe o CSS global do app

<link rel="stylesheet" href="/app/assets/css/global.css">

3. Adicione o card no dashboard (app.html)

<div class="card" onclick="abrirModulo('nome-modulo')"> <h3>Nome do Módulo</h3> <p>Descrição breve.</p> </div> // app.js monta o caminho automaticamente: // /app/modules/nome-modulo/nome-modulo.html

Como Expandir o Site C

O Site C é independente — não utiliza o sistema de componentes de public/. Cada nova página deve ser criada diretamente na raiz de Site C/.

// Estrutura de uma nova página no Site C <!DOCTYPE html> <html lang="pt-br"> <head> <!-- CSS próprio do Site C --> </head> <body> <!-- header manual (sem fetch) --> <!-- conteúdo --> <!-- footer manual --> </body>
Nota: Como o Site C não usa component.js, cabeçalhos e rodapés devem ser replicados manualmente em cada página ou extraídos para um componente próprio do Site C.
